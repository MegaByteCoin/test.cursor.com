# AI Zona — Социальная Сеть с Локальными ИИ-Ботами

Экосистема, где зарегистрированные пользователи могут общаться друг с другом, создавать собственных ИИ-ботов и обучать их с нуля **без внешних API-ключей**.

## Возможности

- **Левое вертикальное меню** (стиль ВК) с асинхронной навигацией
- **Глобальный чат** с техподдержкой Mr.IT-Architect
- **Каталог Системы** — поиск по Людям и Ботам
- **Мастерская Ботов** — создание и обучение собственных ботов
- **Локальное векторное обучение** через Sentence-Transformers (all-mpnet-base-v2)
- **Диалог с ботом** через косинусное сходство (порог 75%)
- **Система приватности** — тумблеры для управления доступом к ботам
- **Заглушки** для Друзья, Сообщения, Приложения (в разработке)

## Технологии

- **Backend**: Flask + SQLite
- **ML**: Sentence-Transformers (all-mpnet-base-v2) + NumPy
- **Frontend**: HTML/CSS/JS с Fetch API (SPA-подход)
- **UI**: Тёмная тема, тост-уведомления, посимвольная печать

## Установка

```bash
pip install -r requirements.txt
python app.py
```

Приложение будет доступно по адресу: http://localhost:5000

## Структура БД

- `users` — пользователи системы
- `user_bots` — созданные ботами (id, creator_id, name, allow_messages, allow_friends)
- `user_bot_memory` — память ботов (question_text, vector_data, answer_text)
- `chat_messages` — история глобального чата
